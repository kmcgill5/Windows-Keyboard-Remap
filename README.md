This project is meant for remapping keys on a windows machine using Registry hacks.

Remap.exe is Remap.cpp compiled and is how you remap the keys. Instructions are provided in the program.
Instructions for remapping your keys using only the Registry are in Instructions.pdf.
Example.png is a picture of a finished Registry remapping.

Keyboard.exe is Keyboard.cpp compiled and returns the scan code and extended flag of keys typed on a pc running Windows.
For a complete list of Scan Codes and their extended flags, look into "Keyboard Scan Codes.pdf".
